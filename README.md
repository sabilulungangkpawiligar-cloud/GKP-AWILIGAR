# GKP-AWILIGAR
Aplikasi berbasis web sederhana untuk mengelola Laporan Pertanggungjawaban (LPJ) keuangan kepanitiaan atau organisasi per komisi/seksi.

🚀 Fitur Utama
Manajemen Komisi/Seksi: 
1.Pencatatan alokasi anggaran khusus untuk tiap divisi.
2.Pencatatan Transaksi: Input pengeluaran dan pemasukan dengan pemformatan mata uang otomatis.
3.Laporan & Rekapitulasi: Pemantauan sisa saldo/kas secara real-time.
4.Export Data: Ekspor riwayat transaksi ke format CSV/Excel.
  Fitur Cetak: Ekspor rekapitulasi ke format PDF/cetak langsung via browser.
5.Penyimpanan Lokal: Menggunakan localStorage sehingga data tersimpan otomatis di browser tanpa memerlukan database tambahan.

🛠️ Teknologi yang Digunakan
1.HTML5 & JavaScript (ES6)
2.Tailwind CSS (via CDN)
3.FontAwesome (Ikon)
